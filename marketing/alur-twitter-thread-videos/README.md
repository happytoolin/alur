# alur Twitter thread videos

Draft Remotion videos for the alur launch thread. Each v7 composition is a
1280x720 landscape, 14-37 second silent product animation mapped to one public
launch tweet.

## Commands

```console
npm i
npm run dev
npm run render:all
```

## Composition IDs

- `alur-launch-node-commands`
- `alur-launch-detects-pm`
- `alur-launch-fast-delegates`
- `alur-launch-normal-node`

Rendered v7 drafts are written to `out/v7/*.mp4`.

## Notes

Animations are frame-based with Remotion helpers, not CSS transitions.
